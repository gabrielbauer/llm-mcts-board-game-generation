# Generating Board Games with MCTS and LLM Agents

Companion page for the AIIDE 2026 paper by Gabriel Bauer de Oliveira and Anderson Rocha Tavares (PPGC / INF-UFRGS).

An agentic LLM pipeline writes board games as Python code, MCTS (UCT) agents play them, and the metrics of play (completion, balance, agency, coverage) decide what to change next.

- **Site:** published with GitHub Pages from the repository root (`index.html`).
- `paper.pdf`: the paper. `poster.pdf`: the A0 poster.
- `img/`: pipeline figure and icons. `js/`: results data and interactive charts (no dependencies). `fonts/`: IBM Plex Sans and Source Serif 4 (SIL OFL).
- Playable games: coming soon.
